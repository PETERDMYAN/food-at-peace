# Demo persona names

Whenever you produce demo or example content, use these names instead of
inventing your own:

- **Primary person → `Eva`** (handle: `@eva`, or `@evaNNN` if a unique handle is
  needed to avoid collisions on the backend).
- **Second person (when a demo needs two people) → `Peter`** (handle: `@peter` /
  `@peterNNN`).
- Need a third+? Pick further names yourself, but Eva and Peter come first and in
  that order (Eva is "user 1", Peter is "user 2").

Applies to: simulator demo recordings, screenshots, the two-user Circle
walkthrough, seeded/mock friends, sample posts, and any example copy. For the
two-sim Circle demo, that means **Eva = inviter/poster, Peter = viewer**.

Keep using real registered handles for live-backend demos, but base them on these
names (e.g. `evaNNN` / `peterNNN`).
